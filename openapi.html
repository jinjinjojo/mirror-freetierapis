    What an OpenAPI file gives you

    An OpenAPI (formerly Swagger) file lists every endpoint of an API, the parameters each takes and the shape of what comes back. Tools turn it into client libraries, mock servers, tests and documentation.

    Largest providers here: . Most specs are for large provider APIs that need a key; for APIs you can call right now with no sign-up, use the console. Where a listed API has a spec, its own page links to it. The descriptions are kept by the open APIs.guru project and released under CC0.
