How we check free APIs

What we measure ourselves, what comes from the community list, what comes from providers' docs, and where the list turned out to be wrong.

Last check run 2026-11-06Re-run weekly; pages say "may be out of date" 14 days after a run.

What the labels mean

  • Measured by us Our own checker sent the request and recorded the answer on 2026-11-06. One request from one connection: a snapshot, not a guarantee.
  • From the public-apis list Copied from the community-maintained public-apis list (MIT): name, description, category, auth and the CORS flag. We don't verify these unless the page shows a measured result next to them.
  • From the provider's docs A usage rule the provider publishes (rate limits, User-Agent rules). Quoted, not measured. 6 tested APIs have one: ip-api, Nominatim, MusicBrainz, Launch Library 2, US Weather and Crossref Metadata Search.

Test calls (hand-picked endpoints)

We picked 114 no-key endpoints and wrote the exact request URL for each (the list only links to docs home pages). Each got one real call with an Origin: https://freetierapis.vercel.app header, the way a web page's request arrives. We record the status, time to first byte, total time with the body, the Access-Control-Allow-Origin header, content type, size, any rate-limit headers and the top-level JSON field names. Plain-HTTP endpoints are also tried over HTTPS.

112 answered with a 2xx status; 2 didn't: Jikan (timeout) and FBI Wanted (HTTP 403).

"Browser OK" means the header was * or our own origin, so a page on any site could read the response. Anything else, or no header, means browser code has to go through a server.

Limits

  • Latency is one request from one connection in one place; yours will differ.
  • No rate-limit headers doesn't mean unlimited: many providers enforce limits without sending headers.
  • An endpoint that answered once can change or go down later. Each page shows the check date, and every tested page has a button that repeats the call from your own browser.
  • We don't test endpoints that need a key or OAuth, so those pages stay out of search results until we can say something the list doesn't.
Checker details

User-Agent FreetierapisChecker/1.0 (+https://freetierapis.vercel.app/method). Docs links: GET, redirects followed, body discarded. Test calls: 8 at a time, Accept: application/json, */*, body read in full. Results are kept in one file per run and every page is rebuilt from it.
